# Three Body Simulation with CUDA and OpenGL

A real-time 3D visualization of the **Three Body Problem** using **CUDA** for physics simulation and **OpenGL** with **GLFW** for rendering.

---

## 🧠 Overview

This project simulates the **gravitational interactions** between **three bodies** using **CUDA** for high-performance computation and **OpenGL** for real-time 3D rendering.

---

## 🛠️ Technologies Used

- **CUDA** – For high-performance gravitational calculations
- **OpenGL** with **GLFW** – For 3D rendering and window management
- **C++** – Core implementation
- **GLAD** – OpenGL loader
- **GLM** – Mathematics library for OpenGL
- **Git** – Version control
- **GitHub** – Hosting

---

## 📦 Requirements

- **NVIDIA GPU** (for CUDA support)
- **Linux (Pop!_OS or similar)**
- **CMake** (for building the project)
- **GCC / G++** (for C++ compilation)
- **CUDA Toolkit** (for GPU computation)
- **GLFW** and **GLAD** (for OpenGL rendering)
